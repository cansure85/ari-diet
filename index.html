        🍽️ 식단 기준

        ✅ 필수

        🥚 간식

        🥒 곁들이

        📲 앳플리 체중 자동 가져오기

        아이폰 단축어를 만들어 홈 화면에 두면, 그 아이콘으로 열 때마다 최신 체중이 들어와요.

        1. 앳플리 앱에서 건강 앱 연동을 켜요.
        2. 단축어 앱 → + → 이름을 아리의 다이어트로 지어요.
        3. 건강 샘플 찾기 추가 → 유형 체중, 정렬 시작 날짜 · 최신 순, 제한 1개.
        4. URL 열기 추가 → 주소에 를 적고, 맨 끝에 앞 단계의 건강 샘플을 넣어요.
        5. 공유 버튼 → 홈 화면에 추가. 앞으로 이 아이콘으로 앱을 열어요.

        체중 숫자는 주소의 # 뒤에 붙어서 서버로 보내지지 않고 폰 안에서만 쓰여요. 기록은 Safari에 저장되니, Safari의 공유 → 홈 화면 추가로 만든 아이콘과 섞어 쓰지 마세요.
